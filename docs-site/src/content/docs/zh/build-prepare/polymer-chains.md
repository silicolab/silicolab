## 目标

用一个重复单元 SMILES 构建 10 个单元的聚苯乙烯链，确认每个单元被记录为一个残基，并在装填之前了解这条链能做什么、不能做什么。

## 构建链

重复单元是带两个 `[*]` 连接点的单体 SMILES：按书写顺序，第一个 `[*]` 连接上一个单元，第二个连接下一个单元。聚乙烯是 `[*]CC[*]`，聚苯乙烯是 `[*]CC([*])c1ccccc1`。在 **Console** 中运行：

```text
polymer build "[*]CC([*])c1ccccc1" --dp 10 --name "PS 10"
```

命令记录会报告 `built polymer PS 10`、新条目的编号（随项目而变）、`162 atoms`、回转半径和端到端距离。链的两端用氢封端。

| 检查项 | 结果 |
| --- | --- |
| 条目名 | `PS 10` |
| 结构计数 | 162 个原子，10 个残基，1 条链 |
| 分子式 | `C80H82` |
| 残基名 | 每个单元都是 `MOA`；用 `--residue PS` 可改名 |
| 周期晶胞 | `none` |

链是逐单元生长的：每个新单元尝试其主链键的所有交叉式旋转异构体，以及绕新键一整圈的扭转角，选接触最少的放置方式，并向前多看一个单元，避免把下一个单元堵死。仍有硬碰撞的连接处再用 UFF 松弛。得到的是自回避、比较伸展的链，不是平衡线团；测量任何性质之前，要先对装填好的盒子做压缩和平衡。相同的 `--seed` 每次运行都给出相同的链；不同的种子给出不同的链，这就是为一个盒子准备多条不同链的方法。

单元本身需要几秒；不松弛时每个连接处远不到一秒，否则耗时主要在 UFF 松弛（release 构建下聚苯乙烯 DP 30 约 25 秒，DP 100 约 90 秒）。如果记录末尾出现 `N close contacts remain`，说明链中有非键合原子的距离低于硬碰撞阈值。换一个 `--seed` 重建，或者在装填后用 `md simulate` 松弛整个盒子。`--no-relax` 会跳过连接处松弛，快得多但留下更多接触。

## 共聚物

按顺序列出每个单元的 SMILES，它们依次标记为 `A`、`B`、……，再用 `--sequence` 给出序列模式；模式会循环到 `--dp`：

```text
polymer build "[*]CC[*]" "[*]CC(C)[*]" --dp 20 --sequence AB --name "PE-PP alternating"
```

共聚物的单元按标签命名为 `MOA`、`MOB`、……。

## 下一步

`polymer build` 只构建一条链。用 **Disordered System** 面板或 `disorder` 命令把多条链装填进模拟盒子，起始密度要远低于目标密度，之后用分子动力学压实。有机链的力场定型尚未提供，所以对聚合物运行 `md build` 目前会在拓扑这一步停下；对含 `[*]` 的 SMILES 直接 `sketch` 会被拒绝，因为通配原子没有三维含义。
