助手可以读取 PDF 的文本——论文、支持信息（SI）或软件手册——并利用其中的内容，
例如复现论文报告的理论级别或 MD 参数。该功能适用于所有模型提供方：SilicoLab
在本地提取文本，只把文本发送给模型。

## 让助手读一个 PDF

把 PDF 拖到 SilicoLab 窗口上，或点击助手输入框里的回形针按钮选择文件。PDF 会以卡片
形式出现在输入框中——鼠标悬停后点击 × 即可移除——每条消息最多附加五个。写下你想让助手
做什么，然后发送。也可以自己输入路径：

```text
阅读 refs/zhang2024.pdf，告诉我他们做几何优化时用了什么泛函、基组和色散校正。
```

读取在后台进行。文本返回后助手才会作答，对话中会出现一条
**Background PDF read** 提示标记这一时刻。

长文档每次只读取若干页。对于长论文或 SI，请提出有针对性的问题：助手可以先在
文档中搜索某个词，再只阅读提到它的页面。让助手注明页码，便于你对照原文核对数值。

## 文件位置决定是否需要确认

| 路径 | 行为 |
| --- | --- |
| 你自己选定的任何文件——作为附件添加，或在消息中输入路径 | 直接读取，不询问。 |
| 位于项目文件夹内，并以相对路径给出（`refs/paper.pdf`） | 直接读取，不询问。 |
| 助手自行选择的其他位置（绝对路径，或包含 `..` 的路径） | 在 **Manual** 和 **Auto (safe)** 模式下显示为 **outside-project read**，需你先批准；**Auto** 模式下不询问直接读取。 |

提取出的文本会和对话的其余内容一样发送给你的模型提供方。请把要用的论文放在项目
文件夹内，不要让助手读取你自己不会粘贴进聊天的文档。

## 限制

- 扫描版 PDF 没有文本层，无法读取；不支持 OCR。
- 图片，以及以图片形式存在的表格，模型看不到。文本表格会以纯文本形式返回，可能
  丢失列对齐——请对照 PDF 核对提取出的数字。
- 无法打开受密码保护的 PDF。
- 超过 64 MB 或 2000 页的文件会被拒绝。
